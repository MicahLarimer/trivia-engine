# Trivia Engine

A Python-based command-line trivia application supporting single-player and pass-and-play multiplayer gameplay.

## Project Overview

Trivia Engine allows players to compete in multiple trivia categories, answer randomized questions, accumulate points, and compare their performance through a persistent leaderboard.

## Planned Features

- Single-player and multiplayer game modes
- Multiple trivia categories
- Selectable difficulty levels
- Randomized question selection
- Multiple-choice questions
- Difficulty-based scoring
- Persistent player statistics
- Game history and leaderboard
- Input validation and error handling
- Automated tests

## Technologies

- Python
- Git and GitHub
- JSON
- Python unittest

## Project Status

Currently in the planning and initial development stage.

## Project Structure

The application will use a modular architecture, separating game logic, player management, scoring, data storage, and terminal interaction.
